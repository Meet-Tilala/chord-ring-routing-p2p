# This file defines CHORD-style connections for N=8 clients

# For client i, fingers point to (i + 2^k) mod N for k = 0, 1, 2, ...

# Client 0: fingers to 1 (0+2^0), 2 (0+2^1), 4 (0+2^2)
# Client 1: fingers to 2 (1+2^0), 3 (1+2^1), 5 (1+2^2)
# etc.
#
# Each client also lists its predecessor so the ring is traversable
# in both directions (predecessor needed for result routing).
